# Build the APK with GitHub Actions

1. Upload the contents of this folder to the root of your GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build Android APK**.
4. If no build is running, choose **Run workflow**.
5. Open the completed build and download the **OpenInDrago-debug-apk** artifact.
6. Extract the downloaded ZIP and install `app-debug.apk` on Android.

Android may ask you to allow installs from your browser or Files app.
